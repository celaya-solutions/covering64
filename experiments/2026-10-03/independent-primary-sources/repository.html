Covering Repository

Welcome to the Covering Repository website

This website collects high-quality covering designs used in wheeling systems (a.k.a. lottery wheeling, lotto designs) and related constructions.

(v,k,t,m)-covering designs

Coverings online: 82.647/108.780 - Improvements since October 2018: 31.071

A (v,k,t,m)-covering design is a collection of k-subsets (blocks) such that every m-subset of v intersects at least one block in at least t points.

Allowed values: 4 ≤ v ≤ 90, 2 ≤ k ≤ 15, 2 ≤ t ≤ 15, 3 ≤ m ≤ 20

(v,k,t)-covering designs

Coverings online: 9.490/9.490 - Improvements since November 1996 (see note below): 98.740

A (v,k,t)-covering design is a collection of k-element subsets of {1,…,v} such that every t-element subset is contained in at least one block.

Allowed values: 4 ≤ v ≤ 99, 3 ≤ k ≤ 25, 2 ≤ t ≤ 8

The parameter ranges above define the supported values, but not every (v,k,t) parameter set within those ranges is open for uploads.
Improvements can be submitted for parameter sets already listed in the repository; additional parameter sets may be added on request.

Note: historical data up to the end of March 2026 are imported from the Dan Gordon Covering Repository.
Improvements and new coverings found after that date are tracked and maintained within this site.
