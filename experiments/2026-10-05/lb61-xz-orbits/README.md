# Draft: orbits of the doubled triples at the degree-20 point

`enumerate.py` lists the graphs X_z (doubled triples through the degree-20
point) up to the 460,800 symmetries of the forced pair structure, with a count
of all labeled cases as a completeness check. It was started once and stopped by
a tool time limit before finishing. It is kept as a starting point for a later
case split and supports no result.
